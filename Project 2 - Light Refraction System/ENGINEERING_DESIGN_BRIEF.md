# Engineering Design Brief - Light Refraction System

## Context

This project presents a light refraction tool concept through systems engineering documentation, CAD revisions, block diagrams, and flowcharts. The main portfolio purpose is to make the design intent and system structure easy to review without relying only on the full report.

## Design Objective

Document and communicate a light-path/refraction system clearly enough that a reviewer can understand the major system blocks, physical design direction, and design-evidence trail from the portfolio folder.

## Intended Users

- Students or reviewers learning how the system is organised.
- Teachers or assessors reviewing the engineering communication and design process.
- Future maintainers who need the reports, CAD revisions, and diagrams to stay connected.

## Requirements

- Preserve the full systems report and concise overview PDF.
- Include a readable block flow diagram and high-level flowchart.
- Preserve editable diagram and CAD evidence where available.
- Keep binary CAD files separated from reviewer-facing Markdown summaries.
- Make source/code availability explicit instead of implying missing code exists.

## Constraints

- Fusion 360 `.f3d` files are binary and do not preview as readable source on GitHub.
- The `Code Revisions` folder contains a Windows shortcut rather than portable source code.
- A reviewer should be able to understand the system at a high level without opening every PDF or CAD file.

## Evidence

- `Project Overview.pdf`
- `Full Systems Engineering Report.pdf`
- `Light Refraction Block Flow Diagram.drawio`
- `Diagrams/Light Refraction Block Flow Diagram.drawio.png`
- `Diagrams/Light Refraction - High Level Flowchart.png`
- `CAD Models/`

## Recommended Improvements

- Add a ray-path diagram showing input light, optical interaction, and output path.
- Add a subsystem responsibility table connecting the block flow diagram to the CAD components.
- Export one or two CAD screenshots as PNG evidence so reviewers do not need Fusion 360 to understand the geometry.
- Replace the Windows `.lnk` shortcut with the original source/code file if it becomes available.
