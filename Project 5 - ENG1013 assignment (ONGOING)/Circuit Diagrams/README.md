# Circuit Diagram Index

This folder contains public-facing circuit evidence for the ENG1013 traffic-control build.

## Files

- `Circuit Diagrams - Redacted.pdf`: redacted PDF export of the supplied circuit diagram set.
- `Exported PNG/`: page-by-page PNG exports for quick portfolio review.
- `Draw.io Source/`: Draw.io source files for the Subsystem 3 circuit diagrams.
- `circuit-diagram-pages.tsv`: page manifest mapping each exported PNG to its original sheet title.

## Public Redaction Note

The original circuit diagram PDF included individual contributor names in sheet title blocks. The public portfolio copy keeps the team attribution and revision/date information while removing individual names.
