# Build and Integration Summary

This summary records the implementation evidence added after the original Milestone 1 planning package.

## Implementation Scope

- Integrated Python control snapshots for Subsystems 1 and 2, Subsystems 2 and 3, and the later combined system.
- Subsystem 3 standalone code for the over-height exit path.
- Wiring notes for the integrated subsystem builds and Subsystem 3 breadboard setup.
- Circuit diagrams exported from the latest circuit diagram PDF.
- Prototype photos and demonstration videos showing the physical system under test.

## Hardware Evidence

The media evidence shows an Arduino and breadboard traffic-control prototype with ultrasonic sensors, LEDs, buttons, LDR sensing, and external test equipment. The photos document the lab build environment, oscilloscope/function-generator test setup, the full breadboard system, and close-up day/night circuit behaviour.

## Code Evidence

The code snapshots preserve both staged integration work and the final integrated source supplied for the portfolio update. Public-facing copies retain team attribution but omit individual contributor names from comments.

## Demonstration Evidence

Five MP4 demonstration files were extracted from the shared Google Photos album and stored in `Evidence/Videos/`. The videos range from short checks to longer working-system demonstrations.

## Public Portfolio Note

The portfolio keeps technical evidence visible while redacting individual student names, student IDs, and staff contact details from public-facing copies where practical.
