# Code Index

This folder preserves Python source snapshots and wiring notes from the ENG1013 traffic-control build.

## Final Integrated System

- `Final Integrated System/Integrated_SUB2+SUB3.py`: integrated Subsystem 2 and Subsystem 3 control file from the submitted code archive.
- `Final Integrated System/Integrated_Sub1+Sub4_Code/`: modular source folder for the integrated Subsystem 1 and Subsystem 4 build, including traffic lights, pedestrian alert, sonar helpers, warning lights, utility functions, and configuration.

## Earlier Integration Snapshots

- `Integrated Subsystems 1 and 2/integrated_subsystems_1_2.py`: earlier integrated control snapshot for Subsystems 1 and 2.
- `Integrated Subsystems 2 and 3/integrated_subsystems_2_3.py`: earlier integrated control snapshot for Subsystems 2 and 3.
- `Subsystem 3/subsystem3_overheight_exit.py`: standalone Subsystem 3 over-height exit implementation.

## Run Context

The code is hardware-facing and expects the ENG1013 Arduino/breadboard setup, Python 3.10.x, and the assignment-approved package set including Pymata4. It is preserved here as implementation evidence rather than a locally runnable software-only project.
