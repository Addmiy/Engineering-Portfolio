# Adheesha M

Engineering and software portfolio focused on practical prototypes: browser AI tools, hardware control systems, mechanical design, CAD evidence, and technical documentation.

## What I Build

- **Browser and AI tools:** Manifest V3 Chrome extension work, OpenRouter API integration, Google Docs companion extraction, local browser storage, and custom graphing workflows.
- **Hardware and control systems:** Arduino/Python traffic-control prototype work with ultrasonic sensing, LDR day/night detection, warning outputs, circuit diagrams, wiring notes, and demonstration videos.
- **Mechanical systems:** Model gearbox design evidence covering gear-ratio planning, CAD renders, fabricated parts, synchroniser constraints, and diagnostic testing.
- **Product prototypes:** Web and mobile app prototypes with HTML/CSS/JavaScript, Expo React Native, TypeScript, Supabase-ready service layers, notifications, and UI iteration.
- **Engineering communication:** Design briefs, flowcharts, block diagrams, reports, evidence indexes, and public redaction notes.
